# Upgrade PdfBox-Android: Apache PDFBox 2.0.27 → 2.0.37

## Context

The port (dormant since Dec 2023) is pinned to PDFBox 2.0.27; upstream's 2.0.x line has 10 releases of fixes since (now 2.0.37, no API breaks — maintenance merge, not a rewrite). Work happens on branch `upgrade/pdfbox-2.0.37` (created; origin=sandeepkrs fork, upstream=TomRoush, both fetched; repo-local `http.sslBackend=schannel` fixes git TLS).

Scope verified by measurement: upstream changed 298 files (+2 new); 279 changed files exist in the port (19 changed-but-dropped files stay dropped); 34 auto-merge clean, 52 need conflict resolution (151 hunks; worst: PageDrawer 24, FileSystemFontProvider 13, SampledImageReader 10). Analysis artifacts in `/tmp`: `hotspot.txt`, `m_clean.txt`, `m_conflict.txt`, `up_changed_port.txt`, `port_deleted.txt`, `up_new.txt`; reference trees `/tmp/pb27`, `/tmp/pb37`; vendored AAR `/tmp/jp2-android-1.0.3.aar`.

## Decisions

- **User**: merge + deps only (no AGP/Gradle/jcenter modernization); push branch to fork only, no upstream PR.
- **Formatting**: refreshed files keep upstream formatting (future 3-way merges stay clean); equivalence checked whitespace-insensitively. Only the 279 upstream-changed files get touched — unchanged files produce no diff, so no giant refresh commit.
- **Transform validated before any repo write**: script round-trips pb27 → port format; acceptance = ~412 mechanical files match existing port files under `diff -w -B` with zero residual hunks. Residuals become the authoritative per-file Android-delta map.
- **Batch order = dependency layers bottom-up** with a compile-closure rule: if compile fails because an un-merged higher layer calls a changed API, pull the minimal caller set into the batch. Never stub.
- Code + its unit tests land in the same commit.
- **Line endings**: repo stores LF (`i/lf w/crlf`, autocrlf=true, no .gitattributes). Script is LF-only; never touch autocrlf; audit `git ls-files --eol` per commit.
- **Never run bare `./gradlew`** (defaultTasks includes `connectedCheck`); always explicit task names.

## Environment preamble (once)

`JAVA_HOME` unset → Corretto 17 on PATH works. Create gitignored `local.properties` with `sdk.dir=S\:\\apps\\android\\sdk`. AGP auto-downloads the missing android-33 platform (license accepted).

## Transform pipeline (`/tmp/tx.sh`, LF in/out, validated by `/tmp/tx-validate.sh`)

Order is load-bearing:
0. Abort on CR in input.
1. `org.apache.fontbox→com.tom_roush.fontbox` then `org.apache.pdfbox→com.tom_roush.pdfbox` (never a loose `org.apache.` rule — would eat commons.logging).
2. `|s|/org/apache/|/com/tom_roush/|` (resource paths/javadoc, after dotted renames).
3. Type remaps longest-first: AffineTransform→harmony; GeneralPath/Path2D/Shape→android.graphics.Path; Point2D→PointF; Rectangle2D→RectF (**before** Rectangle→Rect); Area→Region; BufferedImage→Bitmap; javax.imageio.stream.*→harmony. **Never** remap `java.awt.Color` (AWTColor vs android.graphics.Color, 9+9 files — report-only for manual decision); never touch Graphics2D/Raster/ColorModel/ICC (dropped).
4. Logging: delete `LOG` field; commons-logging imports → `android.util.Log`; `LOG.{warn,error,info,debug,trace}(m[,e])` → `Log.{w,e,i,d,d}("PdfBox-Android", m[,e])`; `isDebugEnabled/isTraceEnabled` → `PDFBoxConfig.isDebugEnabled()` (+conditional import).
5. Import re-grouping (android / java+javax / rest) + dedup **after** remaps; drop unused imports.
6. Strip trailing whitespace. No re-indentation, no scripted Locale hardening (new `String.format` sites flagged for manual `Locale.US`).

Never touch: `android/PDFBoxResourceLoader`, `android/PDFBoxConfig`, `util/GraphicsUtil`, `AndroidFontDirFinder`, `CmapManager` casing, `util/Version.java` (version.properties deliberately absent). Resource-loading fallback (7 sites) re-applied from `pdmodel/font/encoding/GlyphList.java:53-55` pattern during merge, not scripted.

## Per-file conflict procedure (52 files / 151 hunks)

1. Upstream intent: `diff -u pb27 pb37` → classify hunks (bugfix/feature/refactor/javadoc).
2. Android delta: `diff -w -B tx(pb27) port` → classify (platform adaptation / deliberate drop / behavior change).
3. Start from `tx(pb37-file)`; re-apply Android deltas in file order; on collision: upstream semantics wrapped in platform mechanics.
4. Re-apply resource-loader and dropped-feature blocks verbatim from current port.
5. Sanity greps (below); ★ files get a second pass + androidTest targets (`TestRendering`, `PDFontTest`, `JPEGFactoryTest`, `PDImageXObjectTest`).

## Verification

Per content batch: `:library:compileDebugJavaWithJavac` → audit greps → `:library:testDebugUnitTest` (no new failures vs BASELINE-1; failures fixed or waived in commit message) → `./gradlew build test` → commit.

Audit greps (all must hold): zero `org.apache.(pdfbox|fontbox)` refs; zero `org.apache.commons.logging`; `java.awt.` hits only on the dropped-allowlist; zero `LOG.`; `TODO: PdfBox-Android` count ≥ 70; COSName constant diff vs pb37 empty.

Final gate: `clean build test` green; `:sample:assembleDebug`; optional emulator `connectedCheck` (android-35 x86_64 image available; encryption failures get written BC waiver); eol audit `i/lf` everywhere; 12 commits on `master..`.

Push: `git push -u origin upgrade/pdfbox-2.0.37` (fork has only master → new ref; no CI runs on branch; never `./gradlew publish`).

## Top risks

- **PageDrawer semantic merge** (H×H): last batch, second pass, emulator render smoke.
- **FontLoadLevel gating broken** (M×H): invariant grep + font androidTests.
- **BC 1.85.2 behavior changes** (M×M): isolated in C2 with own gate; encryption is androidTest-only → waiver path.
- **Cross-batch compile breaks** (M×M): closure rule; known triggers = fontbox ttf→pdmodel/font, COSParser/StringUtil→everything, Filter/DecodeResult→engines, PDColorSpace cache→graphics callers, closeAndLogException 4 callers, PDFStreamEngine→5 subclasses.
- **Transform bugs** (M×M): round-trip validation + per-batch zero-greps.
- **Upstream refs to dropped classes** = compile errors are the signal; adapt like-for-like (comment + `TODO: PdfBox-Android` + Log fallback), never resurrect.
